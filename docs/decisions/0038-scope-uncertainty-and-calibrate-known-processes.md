# 0038: Scope metadata requirements and calibrate known processes

Date: 2026-10-14
Status: accepted

Keep the complete-panel availability policy unchanged. Prospectively name a
base-unit uncertainty scope without session requirements, and freeze E-015
as bounded known-process estimator calibration under Q-017. Requirements follow
the question; no failed full panel can fall back to this scope automatically.

Session/paragraph metadata are not intrinsic to these two entropy measurements.
Requiring them universally creates an irrelevant blocker; deleting them from
an evaluated full panel would instead be post-hoc selection. A separate frozen
scope avoids both. Test small exact fixtures first, commit the design, then run
the preregistered 288-case grid against theoretical truth with multiplicity and
approximation limits. Reuse existing estimators, environment and experiment ledger.

This is not a classifier, cipher replication or manuscript result. Passing
identifies a tested estimator domain, not broad joint-battery readiness.
See `docs/E015_UNCERTAINTY_CALIBRATION.md`.
