# Cipher-relation representation campaign

E-006 asks whether explicitly relational character measurements can retrieve a
known payload through a completely unseen cipher family more reliably than the
E-005 surface panel. It inherits the complete E-005 benchmark by pinned config
and result hashes. Voynichese is absent.

The primary `fused-character-relation-v1` representation is fixed before its
implementation and combines four views: the old surface baseline, invariant
sequence signatures, modular aligned relationships, and compression distance.
The four components are also reported separately as diagnostics, but none can
replace the primary after execution.

Every primary model excludes a complete cipher family and a complete
four-document fold. Three fixed classifier seeds measure fitting stability.
Same-family/new-document scores show whether a representation can exploit a
known transform without document leakage. Exact decryption supplies an MRR 1.0
implementation ceiling, while fixed position destruction tests whether the
relational score actually uses sequence order.

All eight preregistered gates must pass. Even success only authorizes a new
independently implemented control suite.
